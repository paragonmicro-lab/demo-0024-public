**Read the class here: https://paragonmicro-lab.github.io/demo-0024-public/**

The guides for the Paragon Micro lab class: migrate a Windows + PostgreSQL VM from vSphere to OpenShift

This repository is **generated**: every commit is a snapshot of the class's student materials from the lab's
private source (each commit message names its source commit). Changes made here are overwritten by the next
sync; send corrections to your instructor.

Build the site yourself: `pip install --require-hashes -r requirements.txt && mkdocs serve`.
